WESM Monitoring System

Overview

COGMA is a data automation and monitoring system designed to support energy trading operations and compliance tracking. It streamlines the collection, processing, and visualization of market and operational data, enabling faster and more informed decision-making.

Description

The system automates market data extraction using Selenium-based web scraping, removing the need for manual data collection. Extracted data is stored in PostgreSQL, ensuring structured and reliable access.

Data is visualized through an interactive dashboard built with Streamlit and Plotly, allowing real-time monitoring of key metrics such as RTD, plant output, and market prices.

COGMA also integrates weather data via the Open-Meteo API, providing additional context that may impact plant performance.

Application

COGMA helps traders monitor price movements and analyze variances between RTD and actual output, supporting compliance with FAS, OCC, and DCS requirements.

By centralizing data and automating workflows, the system reduces manual effort, minimizes errors, and improves operational efficiency.

System Architecture

Selenium → Data Extraction → PostgreSQL → Streamlit & Plotly Dashboard → Weather API Integration
