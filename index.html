COGMA System

Python • Django • PostgreSQL

End-to-End Energy Market Data Platform

COGMA is a fully integrated system designed to automate the collection, processing, and visualization of energy market data within WESM environments. It transforms raw inputs into structured, real-time insights for trading and operational monitoring.

The system integrates automated scraping, backend processing using Django, and database storage to create a reliable data pipeline feeding real-time dashboards.

Scraper (Selenium) → Data Processing → Django Backend → PostgreSQL → Dashboard

Applications

• Real-time monitoring of plant schedules and outputs
• Weather-based analysis for solar and hydro generation
• Automated reporting and compliance workflows
• Centralized market data visibility

Reduced manual workload • Improved accuracy • Strengthened compliance • Faster decision-making
